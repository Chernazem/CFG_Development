# Обработка очереди предварительный запрос кредитной истории

## Назначение

Регламент обрабатывает заявки, по которым запущен предварительный запрос кредитной истории. Его задача — подготовить необходимые согласия, выполнить предварительный запрос и расчет ПДН, определить необходимость отказа по основной организации и зафиксировать результат процесса.

## Когда запускается

Задание предопределено, в поставке отключено (`Use = false`). Отдельного файла расписания в выгрузке нет. Задание связано с функциональной опцией `ИспользоватьПредварительныйЗапросКредитнойИстории`.

## Бизнес-логика

Регламент работает как управляющий поток. Сначала он проверяет, что подсистема активна и настроена, затем убеждается, что предыдущие фоновые обработки завершены. После этого выбирает из регистра предварительного запроса заявки в состоянии `ВОбработке`.

Каждая заявка обрабатывается в дочернем фоновом задании. Для заявки регламент:

- при необходимости формирует подписанные сканы соглашений;
- выполняет предварительный запрос кредитной истории и предварительный расчет ПДН;
- сравнивает рассчитанный ПДН с порогом настроек;
- определяет, требуется ли отказ по основной организации;
- при необходимости переводит заявку в отказ или оставляет ручную постобработку;
- фиксирует завершение процесса и результат отказа в регистре.

## Результат работы

После успешной обработки по заявке появляется финальная запись процесса предварительного запроса: `ПроцессЗавершен` и состояние отказа `Отказ` или `НеОтказ`. Дальнейшие шаги заявки используют этот результат для продолжения оформления или отказа.
