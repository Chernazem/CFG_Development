# Обработка очереди на пополнение мобильных номеров

## Точка входа

Регламентное задание вызывает `ПополнениеСчетовМобильныхНомеровСлужебный.ОбработатьОчередь`.

Стек выполнения:

1. `ОбработатьОчередь`
2. `ОбщегоНазначения.ПриНачалеВыполненияРегламентногоЗадания`
3. `ОтправитьЗапросыВСервис`
4. `РегистрыСведений.ОчередьНаПополнениеМобильныхНомеров.ДанныеОчереди`
5. `ОтправитьОчередьВСервис`
6. `ПополнениеСчетовМобильныхНомеров.ОтправитьЗапросВСервис`
7. `РегистрыСведений.ОчередьНаПополнениеМобильныхНомеров.УдалитьИзОчереди`

## Читаемые объекты базы

- `РегистрСведений.ОчередьНаПополнениеМобильныхНомеров` — источник записей на отправку. Читаются поля `Основание`, `НомерТелефона`, `Контрагент`, `Подразделение`, `Организация`, `Сумма`, `Период`.
- `СтандартныеПодключения` по виду `ОчередьПополнениеСчетовМобильныхНомеров` — параметры внешнего канала отправки.
- Константа `ИспользоватьПополнениеСчетовМобильныхНомеров` проверяется при удалении записи из очереди менеджером регистра.

## Изменяемые объекты базы

- `РегистрСведений.ОчередьНаПополнениеМобильныхНомеров` — запись удаляется после успешной отправки во внешний сервис.

Создание записей очереди выполняется не самим регламентом, а программным интерфейсом `ДобавитьДанныеВОчередь`, который валидирует структуру входящих параметров и вызывает `ОчередьНаПополнениеМобильныхНомеров.ДобавитьВОчередь`.

## Что, куда и когда

Регламент берет все текущие записи очереди без дополнительного ограничения порции. Для каждой строки формирует структуру с теми же полями, которые лежат в регистре, и передает ее в `ПополнениеСчетовМобильныхНомеров.ОтправитьЗапросВСервис` вместе с подключением.

Удаление из очереди происходит только после успешного вызова отправки. Если внешний сервис или подключение вернули ошибку, исключение пробрасывается выше, а обработка очереди останавливается. Это делает повтор безопасным: записи, которые не были подтвержденно отправлены, остаются в базе.
