# Обработка очереди на пополнение мобильных номеров

## Назначение

Регламент отправляет во внешний сервис заявки на пополнение счетов мобильных номеров, которые накопились в очереди 1С. Очередь наполняется из бизнес-процессов, где клиенту или сотруднику требуется компенсировать или оплатить мобильную связь.

## Когда запускается

Задание предопределено, но в поставке отключено (`Use = false`). Расписание настроено на ежедневный запуск с 11:00 и повтором раз в 3600 секунд.

## Бизнес-логика

При запуске регламент читает все записи очереди пополнения мобильных номеров. В каждой записи хранятся номер телефона, сумма, контрагент, подразделение, организация и основание пополнения.

Если очередь пуста, регламент только пишет информационное сообщение в журнал. Если записи есть, каждая строка преобразуется в структуру запроса и отправляется во внешний сервис через стандартное подключение `ОчередьПополнениеСчетовМобильныхНомеров`.

После успешной отправки конкретная запись удаляется из очереди. Если отправка любой строки завершается ошибкой, обработка текущего запуска останавливается исключением: неотправленные записи остаются в очереди и будут повторены при следующем запуске.

## Результат работы

Успешно отправленные заявки исчезают из очереди. Неотправленные или ошибочные заявки остаются в регистре очереди и не теряются. Получение финальных статусов пополнений выполняет отдельное регламентное задание получения состояний.
