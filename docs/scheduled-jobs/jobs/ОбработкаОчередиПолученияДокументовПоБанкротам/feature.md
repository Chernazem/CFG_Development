# Обработка очереди получения документов по банкротам

## Назначение

Регламент получает PDF-документы по сообщениям Федресурса о банкротстве и прикрепляет их к документам `Запрос информации о банкротстве`. Он завершает цепочку, где ранее был отправлен запрос на получение PDF по конкретному сообщению о банкроте.

## Когда запускается

Задание предопределено, но в поставке отключено (`Use = false`). Расписание настроено на повтор каждые 60 секунд.

## Бизнес-логика

Регламент слушает очередь ответов сервиса получения документов по банкротам. Каждое сообщение связывается с исходным запросом через `CorrelationId`: по нему находится сообщение в проведенном документе запроса информации о банкротстве.

Если ответ сервиса успешный и содержит ссылку на PDF, регламент скачивает файл по HTTP, добавляет его как присоединенный файл к документу запроса и называет файл по номеру и дате сообщения.

Для судебного банкротства регламент может закрыть дело, если документ ожидал завершения и получение PDF подтверждает финальный этап. Для внесудебного банкротства после получения PDF может быть запущено списание задолженности, если организация есть в списке кредиторов и выполнены условия списания.

## Результат работы

Документы по банкротству получают присоединенный PDF-файл. В отдельных сценариях дополнительно меняется состояние дела и запускается списание безнадежной задолженности. Ошибки получения ссылки, скачивания файла или некорректного ответа сервиса пишутся в журнал регистрации.
