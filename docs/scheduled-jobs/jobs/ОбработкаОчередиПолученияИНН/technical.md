# Обработка очереди получения ИНН

## Точка входа

Регламентное задание вызывает `ПолучениеИНН.ОбработатьОчередь`.

Стек выполнения:

1. `ОбработатьОчередь`
2. `ОбщегоНазначения.ПриНачалеВыполненияРегламентногоЗадания`
3. `ОбработкаОчереди`
4. `ЗапросОбработкаОчереди`
5. `ОбработатьТекущуюВыборкуОчереди`
6. `ПолучитьИННОбъекта`
7. `ЗапросВСервис`
8. `РезультатОбращенияКСервисуПолученияИНН`
9. `ОбработатьПолученныеСообщения`
10. `ЗаписатьИННОбъекта`
11. `ЗаписатьСостояниеПолученияИНН`

## Читаемые объекты базы

- `РегистрСведений.СостоянияПолученияИНН` — очередь объектов в состояниях `Очередь` и `СервисНедоступен`.
- `Справочник.Контрагенты` и `Справочник.ФизическиеЛица` — читаются ИНН, дата рождения и табличные части документов.
- `РегистрСведений.ФИОФизическихЛиц` — получение актуального ФИО.
- `РегистрСведений.СоответствиеВидовДокументовФизЛицДляВнешнихСистем` — код документа для сервиса, если документ не паспорт РФ.
- `СтандартныеПодключения` по виду `ПолучениеИНН` — очередь RPC-запроса к внешнему сервису.
- Константа `КонфигурацияДляНерезидентов` влияет на отбор документа: по номеру документа или по виду `ПаспортРФ`.

## Изменяемые объекты базы

- `Справочник.Контрагенты` или `Справочник.ФизическиеЛица` — записывается найденный ИНН.
- `РегистрСведений.СостоянияПолученияИНН` — фиксируется новое состояние `Получено`, `СервисНедоступен` или `Ошибка`, а также дата обновления.

Очередь пополняет метод `ПоместитьОбъектыВОчередь`: он проверяет текущий ИНН объекта и пишет состояние `Очередь` только для объектов, где ИНН не заполнен или содержит признак отсутствия.

## Что, куда и когда

Регламент выбирает до 1000 объектов из регистра состояний. Запрос собирает последние документы удостоверения личности из табличных частей контрагентов и физических лиц, затем передает в обработку объект, дату рождения, вид документа, серию и номер.

Для объекта с уже заполненным ИНН повторный запрос не выполняется. Для объекта без ИНН формируется JSON с `first_name`, `last_name`, `middle_name`, `birthday`, `doctype`, `docno` и отправляется через `ОтправитьСообщенияЧерезRPC`.

Ответ `status = ok` с заполненным `inn` приводит к записи ИНН и состоянию `Получено`. Ошибка с текстом про капчу считается временной недоступностью сервиса и переводит запись в `СервисНедоступен`. Остальные проблемы дают состояние `Ошибка`.
