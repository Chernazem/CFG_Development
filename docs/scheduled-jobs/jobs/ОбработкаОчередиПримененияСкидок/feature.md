# Обработка очереди применения скидок

## Назначение

Регламент применяет скидки по договорам займа после поступления оплат. Очередь формируется при записи расчетов по займам, когда по договору появился возврат займа и тип регистратора поддерживается механизмом скидок.

## Когда запускается

Задание предопределено, но в поставке отключено (`Use = false`). Отдельного файла расписания в выгрузке нет. Работа зависит от константы `ИспользоватьСкидки` и активных настроек подсистемы скидок.

## Бизнес-логика

Регламент проверяет настройки скидок, ждет завершения ранее запущенных фоновых заданий применения скидок и выбирает порцию договоров из очереди. Затем договоры распределяются по дочерним заданиям.

Для каждого договора рассчитываются доступные скидки. Если есть скидка, которая еще не применена и условия которой выполнены, выбирается наиболее приоритетная. Поддержанный алгоритм переносит оплаченные проценты в тело займа и предоставляет процентную скидку через изменение условий.

Алгоритм применения может отменять проведение более поздних изменений условий, создавать новое изменение условий, создавать корректировки займа, отменять и заново проводить оплаты с перераспределением. После успешного применения запись удаляется из очереди.

## Результат работы

По договору применяются финансовые изменения, необходимые для скидки, а факт применения фиксируется в регистрах скидок. Если обработка договора завершилась ошибкой, запись остается в очереди с признаком ошибки и описанием, чтобы ее можно было разобрать вручную.
