## Что приняли без возражений

- Auth: только `POST /api/v1/auth/token` + Bearer, TTL час.
- Select: два `offer_id` составляющих, сервис сворачивает в комбо. В матрице сравнения (APNS-005) заводим статус «свёрнуто в комбо», чтобы скидка пары не считалась дефектом цены.
- `ends_at` = дата окончания **договора займа**, ISO-8601 с явным смещением.
- `POST /api/v1/offerings/release` с `external_ref` + `client_refused` | `payment_missing`. После confirm — только `/sales/cancel`.
- `legacy_setting_id` = `Code` настроек (9 символов с ведущими нулями). Таблица каналов из Q-05 идёт в APNS-003.
- Не слать `signed_at` / `paid_at`, если нет фактического момента.

Стенд: пилот на нём пока без `unemployment` и без комбо — shadow по этим позициям не сравниваем, пока каталог стенда не догонит.
