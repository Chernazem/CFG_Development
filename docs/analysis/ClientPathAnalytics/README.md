# Аналитика клиентского пути

Каталог артефактов по улучшению аналитики клиентского пути. Номера задачи (Jira / DEV) пока нет: обсуждения и выводы складываем сюда, чтобы не терять их до заведения задачи.

Исходная формулировка на 2026-10-29 — карточка «Сквозная аналитика оформления займа». 2026-10-30 продакт передал перечень признаков и SQL витрины «клиент × день». Рабочая граница первой итерации: ТБ пишет журнал действий, витрина считает флаги и разрезы.

## Как вести каталог

- Обсуждение и вывод — отдельная запись в [discussions.md](discussions.md): дата, что решили, что осталось открытым.
- Исходные материалы (скрины, выгрузки, цитаты) — в `sources/`, рядом короткая заметка, откуда фрагмент и что в нём неразборчиво.
- Когда появится номер задачи, ссылку на него добавить в этот README. Второй каталог под ту же тему не заводить.
- Креды, персональные данные клиентов и выгрузки с ПДн в каталог не класть.
