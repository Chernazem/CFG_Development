# Поиск в Confluence (wiki)

## Когда применять

- Пользователь спрашивает «где в wiki», «что делать если», «как настроить», «инструкция по».
- Нужен runbook по инциденту (обмен ERP, блокировки, интеграции, TB API и т.п.).
- Перед изменением конфигурации — проверить, есть ли уже описанный процесс в Confluence.

## Быстрый старт

Скрипт: `.cursor/skills/confluence-wiki-search/confluence_search.py`

```bash
export CONFLUENCE_SEARCH_API_KEY='<X-API-KEY>'
python3 .cursor/skills/confluence-wiki-search/confluence_search.py "остановился обмен ЕРП что делать"
```

Или с явным URL (если отличается от дефолтного):

```bash
CONFLUENCE_SEARCH_URL='https://n8n-dev.centrofinans.ru/webhook/confluence-search' \
CONFLUENCE_SEARCH_API_KEY='<X-API-KEY>' \
python3 .cursor/skills/confluence-wiki-search/confluence_search.py --query "текст запроса"
```

## API

| Параметр | Значение |
| --- | --- |
| Метод | `POST` |
| URL по умолчанию | `https://n8n-dev.centrofinans.ru/webhook/confluence-search` |
| Авторизация | заголовок `X-API-KEY: <ключ>` |
| Тело | `{"query": "<поисковая строка>"}` |
| `Content-Type` | `application/json` |
| Таймаут | до 90 с (ответ n8n может идти 20–40 с) |

Альтернатива без скрипта — `curl`:

```bash
curl -s -X POST \
  -H "X-API-KEY: ${CONFLUENCE_SEARCH_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{"query": "текст запроса"}' \
  "${CONFLUENCE_SEARCH_URL:-https://n8n-dev.centrofinans.ru/webhook/confluence-search}"
```

## Переменные окружения

| Переменная | Обязательна | Описание |
| --- | --- | --- |
| `CONFLUENCE_SEARCH_API_KEY` | да | ключ для заголовка `X-API-KEY` |
| `CONFLUENCE_SEARCH_URL` | нет | URL webhook; по умолчанию n8n-dev |

Ключ не коммить в репозиторий. Храни в локальном `env`/`.env` или передай пользователем в сессии.

## Формат ответа

Webhook возвращает **markdown** с:

- заголовком и **запросом**;
- **лучшей статьёй**: название, ссылка, коллекция, релевантность (%), `pageId`;
- **кратким ответом** (summary);
- **содержанием** (выдержка);
- списком **других подходящих статей**.

## Как отвечать пользователю

1. Выполни поиск по сути вопроса (на русском, как спросил пользователь).
2. В ответе дай:
   - ссылку на главную статью;
   - краткий actionable summary из «Краткий ответ»;
   - ключевые шаги из «Содержание» (команды, URL Grafana/Graylog, фильтры);
   - при необходимости — 1–2 альтернативные статьи.
3. Если релевантность низкая (<70%) или статей нет — скажи об этом и предложи уточнить запрос.

## Формулировка запроса

- Пиши запрос **естественным языком**, как вопрос коллеге: «остановился обмен ЕРП что делать», «как проверить блокировки erp_cfg».
- Для узкой темы добавь контекст: продукт (TB, ERP, ДО), симптом, объект (регистр, обмен, API).
- Если первый ответ слабый — переформулируй (синонимы: ЕРП/ERP, обмен/интеграция) и повтори поиск.

## Ошибки

| Симптом | Действие |
| --- | --- |
| HTTP 401/403 | проверь `CONFLUENCE_SEARCH_API_KEY` |
| Таймаут | повтори запрос; n8n может отвечать долго |
| Пустой ответ | уточни запрос или проверь доступность `n8n-dev.centrofinans.ru` |
| Не JSON/markdown | выведи сырой ответ и сообщи о сбое webhook |

## Безопасность

- Только чтение (поиск); webhook не изменяет wiki.
- Не логируй и не цитируй API-ключ в ответах и коммитах.
