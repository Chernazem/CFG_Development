# Как проверить тип параметра (БСП)

Только `ОбщегоНазначенияКлиентСервер.ПроверитьПараметр`. Не `ТипЗнч`, не `ВызватьИсключение`, не свой хелпер.

```bsl
ИмяМетода = "ИмяМодуля.ИмяМетода";
ОбщегоНазначенияКлиентСервер.ПроверитьПараметр(ИмяМетода, "АдресСервиса", АдресСервиса, Тип("Строка"));
```

Несколько типов, структура, необязательный параметр — [reference.md](reference.md).

Значение — навык `1c-bsp-check`. Где в публичном API тип обязателен — `1c-public-api-param-types`.
