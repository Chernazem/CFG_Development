# ПроверитьПараметр

Источник: `ОбщегоНазначенияКлиентСервер` (БСП). Исключение, если тип `ЗначениеПараметра` не входит в `ОжидаемыеТипы`. Текст исключения хелпер собирает сам.

```bsl
ОбщегоНазначенияКлиентСервер.ПроверитьПараметр(
	ИмяПроцедурыИлиФункции, // Строка — "Модуль.Метод"
	ИмяПараметра,           // Строка
	ЗначениеПараметра,      // Произвольный
	ОжидаемыеТипы,          // ОписаниеТипов, Тип, Массив, ФиксированныйМассив, Соответствие, ФиксированноеСоответствие
	ОжидаемыеТипыСвойств);  // Структура, необязательный; только если значение — Структура
```

Аргументы — литералы, `Тип("...")` и переменные. Не вкладывать сборку массива/структуры типов в вызов.

`ВызватьИсключение` запрещён как замена проверки типа. Сбой внешнего API, «объект не найден» после проверки типа — не этот хелпер.

## ОжидаемыеТипы

| Форма | Когда |
|-------|--------|
| `Тип("Строка")` | один тип |
| `Новый Массив` + `Добавить(Тип(...))` | несколько типов |
| `Метаданные.ОпределяемыеТипы.Имя.Тип` | определяемый тип (`ОписаниеТипов`) |
| `Соответствие` / `ФиксированноеСоответствие` | ключ = допустимый `Тип` |

Ссылка: `Тип("СправочникСсылка.Имя")`.

`Неопределено` хелпер сам по себе не считает допустимым.

## Необязательный параметр

Если по контракту допустимы `Неопределено` / пусто по умолчанию — тип проверять только если значение передано. Не добавляй `Тип("Неопределено")` «на всякий случай».

```bsl
Если ОповещениеОЗавершении <> Неопределено Тогда
	ОбщегоНазначенияКлиентСервер.ПроверитьПараметр(
		ИмяМетода, "ОповещениеОЗавершении", ОповещениеОЗавершении, Тип("ОписаниеОповещения"));
КонецЕсли;
```

## ОжидаемыеТипыСвойств

Ключ — имя свойства, значение — ожидаемый тип (те же формы). Хелпер проверяет наличие свойства и тип. Собирать в переменную.

```bsl
ТипыСвойств = Новый Структура;
ТипыСвойств.Вставить("АдресWSDL", Тип("Строка"));
ТипыСвойств.Вставить("ИмяСервиса", Тип("Строка"));
ОбщегоНазначенияКлиентСервер.ПроверитьПараметр(
	ИмяМетода, "Параметры", Параметры, Тип("Структура"), ТипыСвойств);
```

Свойство, которое по контракту может быть `Неопределено`, не класть в эту структуру (или вставлять только если заполнено).

## Запрещено

```bsl
Если ТипЗнч(ИмяНоды) <> Тип("Строка") Тогда
	ВызватьИсключение "Ожидалась строка";
КонецЕсли;
```
