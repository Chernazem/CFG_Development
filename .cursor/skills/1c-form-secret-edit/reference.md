# #std740 — Безопасное хранение паролей (выжимка)

Источник: https://its.1c.ru/db/v8std#content:740:hdoc  
Сайт не открывать: страница за логином, достаточно этого файла и `SKILL.md`.

- Режим пароля на поле — только маскировка ввода, не защита. Если в реквизите формы лежит реальный пароль, при открытии он уходит на клиент открытым текстом.
- Пароль не хранить в реквизитах формы как значение. На клиент — признак заполнения: `УникальныйИдентификатор` формы или пустая строка.
- Реальное значение читать и писать только на сервере (безопасное хранилище). Новый пароль может прийти с клиента при вводе.

## Эталон

ТБ, `Справочник.ТочкиПодключенияS3`: форма элемента (`PasswordMode`, `СекретныйКлючПриИзменении`); менеджер — `ПрочитатьПараметрыДоступа` / `ЗаписатьПараметрыДоступа` / `УстановитьПредставлениеСекретногоКлюча`.
