# Редактирование секрета на форме 1С

**Секрет не должен покидать сервер.** На клиент при открытии и после записи — только `""` или `УникальныйИдентификатор` формы. Реальное значение читать и писать только на сервере. Новый секрет может прийти с клиента.

## Что сделать

На каждое секретное поле:

1. **Форма.** Реквизит секрета (строка) + скрытый булев `…Изменен`. Поле ввода: `PasswordMode`. Обработчик `ПриИзменении`: `…Изменен = Истина`.
2. **Открытие (сервер).** Прочитать секрет из хранилища. Пустой → `""`. Заполненный → `УникальныйИдентификатор` формы. `…Изменен = Ложь`.
3. **Любое изменение** (пользователь или код) → `…Изменен = Истина`.
4. **Сохранение (сервер).** Если `…Изменен` — записать реквизит в хранилище, затем снова шаг 2. Иначе хранилище не трогать. «Меняли ли» — только флаг, не сравнение поля с маской.

```bsl
Процедура УстановитьПредставлениеСекрета(Секрет, Форма)
	
	Если ПустаяСтрока(Секрет) Тогда
		Форма.Секрет = "";
	Иначе
		Форма.Секрет = Форма.УникальныйИдентификатор;
	КонецЕсли;
	
	Форма.СекретИзменен = Ложь;
	
КонецПроцедуры
```
