# Как проверить значение параметра (БСП)

Только `ОбщегоНазначенияКлиентСервер.Проверить`. Не `ВызватьИсключение`, не свой assert.

Сначала тип (навык `1c-bsp-check-parameter`), потом значение.

```bsl
ИмяМетода = "ИмяМодуля.ИмяМетода";
ОбщегоНазначенияКлиентСервер.Проверить(
	ЗначениеЗаполнено(АдресСервиса),
	"Не указан адрес сервиса.",
	ИмяМетода);
```

Сообщение — строка, `СтрШаблон` в одну строку или переменная. Правила подстановки — [reference.md](reference.md).

Где в публичном API значение желательно — `1c-public-api-param-types`.
