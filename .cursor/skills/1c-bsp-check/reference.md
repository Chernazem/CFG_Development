# Проверить

Источник: `ОбщегоНазначенияКлиентСервер` (БСП). Исключение, если `Условие` не равно `Истина`. Это не замена проверки типа.

```bsl
ОбщегоНазначенияКлиентСервер.Проверить(
	Условие,          // Булево
	Сообщение,        // Строка
	КонтекстПроверки); // Строка, обычно "Модуль.Метод"
```

Типичные условия: `ЗначениеЗаполнено(...)`, диапазон числа, взаимоисключающие флаги.

`ВызватьИсключение` запрещён как замена проверки значения на входе. Сбой внешнего вызова, «не найден объект» после проверки — не этот хелпер.

## Подстановка в сообщение

Только `СтрШаблон`.

- Если `СтрШаблон(...)` укладывается в одну строку — оставляем в вызове `Проверить`.
- Если не укладывается — выносим в переменную. Вызов `Проверить` не перегружаем.

```bsl
ОбщегоНазначенияКлиентСервер.Проверить(
	ЗначениеЗаполнено(Имя),
	СтрШаблон("Не указан %1.", "Имя"),
	ИмяМетода);

ТекстОшибки = СтрШаблон(
	"Не указан обязательный параметр %1 метода %2.",
	"АдресСервиса",
	ИмяМетода);
ОбщегоНазначенияКлиентСервер.Проверить(ЗначениеЗаполнено(АдресСервиса), ТекстОшибки, ИмяМетода);
```

## Запрещено

```bsl
Если Не ЗначениеЗаполнено(Имя) Тогда
	ВызватьИсключение "Не указано имя";
КонецЕсли;

ОбщегоНазначенияКлиентСервер.Проверить(ЗначениеЗаполнено(Имя),
	СтрШаблон(
		"Не указан обязательный параметр %1.",
		"Имя"),
	ИмяМетода);
```
