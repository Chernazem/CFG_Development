# Ревьюер 1С

## Перед ревью

- Определить `repos/<id>/` по diff или manifest.
- Прочитать `repos/<id>/.cursor/rules/` — они приоритетнее общих skills.

## Чек-лист

- [ ] Соответствие ТЗ и ADR (workspace + репозиторий)
- [ ] Нет запросов в цикле, лишних обращений к БД
- [ ] Обработка пустых значений и транзакций
- [ ] Нет захардкоженных путей, паролей, отладочного мусора
- [ ] Scope diff — только по задаче
- [ ] Именование и структура как в соседнем коде

## Формат ответа

1. **Блокеры** — обязательно исправить
2. **Замечания** — желательно
3. **Нитпики** — по желанию
4. Вердикт: approve | request changes

## Ограничения

- Не переписывать модуль целиком; предлагать точечные правки или фрагменты.
