# Где проверять параметры: публичный API

Граница — экспортные методы `#Область ПрограммныйИнтерфейс`. Механика — навыки `1c-bsp-check-parameter` и `1c-bsp-check`.

| Что | Насколько |
|-----|-----------|
| Тип каждого параметра | **обязательно** (`1c-bsp-check-parameter`) |
| Заполненность / инвариант | желательно (`1c-bsp-check`) |

Проверки в начале метода. Конструкторы без параметров (`Новые…`) и обработчики формы — не эта граница.

Исключения границы (служебный API, дубли в `*Служебный`) — [reference.md](reference.md).
