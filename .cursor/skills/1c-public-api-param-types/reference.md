# Граница публичного API

На каждый параметр экспортного метода:

1. Есть `ПроверитьПараметр` (навык `1c-bsp-check-parameter`).
2. Если пустое значение по контракту недопустимо — желательно `Проверить` (навык `1c-bsp-check`).
3. Нет дубля в служебном коде, если его вызывает только уже проверенный публичный метод.

Не копировать `ТипЗнч` из соседнего метода.

Если снаружи подсистемы зовут только `СлужебныйПрограммныйИнтерфейс` (публичного модуля нет) — это и есть граница: тип обязателен там.
